# Dota 2 Silencer Mod

Программа для отключения звуковых фраз колеса чата, насмешек и граффити в Dota 2. Подменяет выбранные ресурсы заглушками, не изменяя оригинальные файлы игры.

## ⚠️ Важное условие

Мод работает **только с русской озвучкой игры**.

Начиная с обновления от июля 2026 года, язык интерфейса и язык озвучки в Dota 2 — это две независимые настройки. Игра подгружает языковую папку по языку озвучки (`AudioLanguage` в `game/dota/cfg/boot.vcfg`), поэтому для работы мода необходимо:

- в свойствах Dota 2 в Steam выбран русский язык;
- в настройках самой игры язык озвучки — русский;
- в параметрах запуска отсутствуют `-language` и `-audiolanguage`.

Для английской и других озвучек метод не работает: игра не монтирует отдельную языковую папку (например, `dota_english` не существует), поэтому переопределять файлы нечем.

## 📌 Что можно отключить

Каждая категория включается отдельно. По умолчанию включены первые четыре категории, сезонные события и граффити — это соответствует назначению предыдущих версий. Реплики героев и насмешки по умолчанию выключены.

| Категория | Содержимое |
|---|---|
| **Dota Plus и саундборд** | Барабанная дробь, сверчки, смех, аплодисменты, классические и общие эффекты колеса чата |
| **The International** | Реплики комментаторов и эффекты TI10–TI13, старые сообщения TI, отдельный набор TI2021 и Voice of God 2025 |
| **Кастеры и сообщество** | Пакеты личностей сообщества из `sounds/talentcontent`, сезоны 11–13 |
| **Фанатские наборы команд** | Сезонные и командные наборы из `sounds/teamfancontent`, кроме файлов отдельного набора комментаторов TI2021 |
| **Реплики героев в колесе** | Сообщения из официального `chat_wheel_heroes.txt`; в безопасном режиме — только выделенные файлы `*_wheel_*` |
| **Насмешки героев** | Только звуки обычных насмешек; Siltbreaker, анимации, модели и частицы не затрагиваются |
| **Реплики сезонных событий** | Crownfall, Dark Carnival, Frostivus, Dragon's Blood, Diretide, fall2021 и сообщения 10-летия Dota 2 |
| **Граффити и звук напыления** | Все текстуры из `materials/particle/sprays` и звук `spraypaint.vsnd_c` |

Для TI, событий и реплик героев программа читает официальные `chat_wheel`-скрипты и `soundevents`, поэтому используются точные связи сообщений с фактическими аудиофайлами. Широкий паттерн `sounds/misc/crownfall/**` не применяется: музыка и эффекты мини-игр Crownfall не заглушаются.

### Полный режим реплик героев

Переключатель **«Отключить всё, включая обычные реплики»** расширяет категорию со специальных `*_wheel_*` файлов до всех сообщений героев в колесе чата. Он по умолчанию выключен.

**Внимание:** Valve повторно использует эти аудиофайлы в обычной озвучке. Полный режим заглушает часть обычных реплик героев вне колеса чата — это ограничение ресурсов игры, а не ошибка программы.

Файлы разных категорий также могут пересекаться. Если один файл выбран хотя бы в одной активной категории, он будет заглушён. Обнаруженные пересечения выводятся в журнал.

Все замены собираются в один архив `pak02_dir.vpk` в папке `game/dota_russian`, который игра подгружает автоматически. Оригинальные архивы игры не изменяются.

## 🚀 Использование

1. Подготовьте игру согласно разделу «Важное условие».
2. Скачайте последний релиз и распакуйте архив (рядом с `DotaSoundSilencer.exe` должна лежать папка `tools`).
3. Запустите `DotaSoundSilencer.exe`. Путь к Dota 2 обычно определяется автоматически; если нет — укажите папку `dota 2 beta` вручную кнопкой «Изменить».
4. Отметьте нужные категории. Кнопки «Выбрать все» и «Снять все» управляют всем списком, счётчик показывает число выбранных пунктов.
5. Нажмите «Применить мод». Ход работы отображается в строке состояния; подробности доступны по кнопке «Показать журнал».
6. Перезапустите Dota 2.

## 🔄 После обновления Dota 2

Запустите программу ещё раз: список файлов, официальные определения и sound events будут перечитаны из актуального `pak01_dir.vpk`, после чего архив пересоздастся с учётом новых файлов.

## ❌ Удаление и восстановление

Нажмите **«Восстановить всё»** и подтвердите удаление. Программа удалит только созданный `game/dota_russian/pak02_dir.vpk`.

Тот же результат даёт ручное удаление этого файла. После перезапуска игры исходные звуки и граффити вернутся.

## ❓ Частые вопросы

**Звуки остались после применения.**
Проверьте язык озвучки: в файле `game/dota/cfg/boot.vcfg` должно быть `"AudioLanguage" "russian"`. Убедитесь, что файл `pak02_dir.vpk` появился в `game/dota_russian`. Если программа не смогла создать файл — запустите её от имени администратора.

**Почему исчезли обычные реплики героев?**
Проверьте полный режим в категории «Реплики героев в колесе». Выключите его и примените мод заново. Также учитывайте возможные пересечения файлов между выбранными категориями.

**Граффити не исчезли / видны артефакты.**
Мод подменяет только текстуры в `materials/particle/sprays/`. Если Valve добавит спреи по другим путям — напишите в Issues, обновлю паттерны.

**Это безопасно для VAC?**
Мод не изменяет оригинальные архивы игры и не вмешивается в её процесс — используется штатный механизм языковых VPK-архивов. За всё время использования блокировок не было. Тем не менее, любые модификации вы устанавливаете на свой страх и риск.

## 🛠️ Сборка из исходников

> Полная документация для разработчиков и AI-агентов — в [AGENTS.md](AGENTS.md).

Требуется Python 3.11+.

```bash
pip install -r requirements.txt
pyinstaller buildbuild.spec --clean --noconfirm
```

Готовый `DotaSoundSilencer.exe` появится в `dist/`. Для работы программы скопируйте папку `tools` (с `vpk.exe` и `vrf_cli.exe`) рядом с exe.

Инструменты в репозиторий не входят:
- `vpk.exe` — из Source SDK (папка `tools/vpk/`);
- `vrf_cli.exe` — из релизов [ValveResourceFormat](https://github.com/ValveResourceFormat/ValveResourceFormat/) (папка `tools/vrf/`).
