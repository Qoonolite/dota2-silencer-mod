Dota 2 Silencer Mod
Отключение надоедливых звуковых фраз колеса чата в Dota 2 (только для русской версии)

⚠️ Важное предупреждение
Данный мод работает ТОЛЬКО для клиентов Dota 2 с русским языком интерфейса и озвучкой.
Для английской, китайской, корейской и других версий метод не работает из-за изменений в механизмах загрузки VPK-файлов.

📌 Что делает мод?
Находит все звуковые файлы из папок teamfancontent и talentcontent (именно там хранятся раздражающие фразы из компендиумов, аркан и имморталов).

Заменяет их на тишину (длительностью менее 1 секунды).

Создаёт дополнительный архив pak02_dir.vpk в папке dota_russian, который автоматически подгружается игрой, переопределяя оригинальные звуки.

Не изменяет оригинальные файлы игры и не нарушает целостность – мод безопасен для VAC.

🔧 Требования
Русская версия Dota 2 (текст + озвучка).

Установленный vpk.exe (Source 1) – для упаковки архива.

Установленный vrf_cli.exe (ValveResourceFormat) – для чтения VPK-архивов.

📦 Где взять инструменты?
Инструменты не входят в репозиторий из-за большого размера. Скачай их отдельно:

1. vpk.exe (Source 1 Tools)
Входит в состав Source SDK или может быть взят из старых установок Steam.
Если у тебя нет – скачай архив с готовыми файлами (ссылка будет в релизе).

2. vrf_cli.exe (ValveResourceFormat)
Скачай с официального репозитория:
👉 ValveResourceFormat Releases
Выбери cli-windows-x64.zip (последняя версия), распакуй и положи vrf_cli.exe в папку tools/vrf/.

🚀 Как пользоваться (готовый .exe)
Скачай последний релиз с GitHub (файл DotaSoundSilencer.exe).

Положи папку tools рядом с .exe (следуя структуре выше).

Запусти DotaSoundSilencer.exe.

Программа автоматически попытается найти папку dota 2 beta.

Если не нашла – укажи путь вручную (до папки dota 2 beta).

Нажми кнопку «ПРИМЕНИТЬ».

Дождись завершения обработки (в окне лога будет виден прогресс).

Перезапусти Dota 2 – звуки колеса чата должны исчезнуть.

🔄 Как обновить мод после патча Dota 2?
Просто запусти программу заново – она перечитает актуальные звуковые файлы и пересоздаст архив.
Никаких дополнительных действий не требуется.

❓ Часто задаваемые вопросы
Что делать, если звуки остались?

Проверь, что в настройках Steam выбран русский язык и в параметрах запуска нет -language.

Убедись, что в папке ...\dota 2 beta\game\dota_russian\ появился файл pak02_dir.vpk.

Если его нет – запусти программу от имени администратора.

Мод отключает только колесо чата?
Да, сейчас мод затрагивает только звуковые фразы из компендиумов и аркан (папки teamfancontent и talentcontent). Остальные звуки (голоса героев, уведомления, музыка) остаются нетронутыми.

Как удалить мод?
Удалите файл pak02_dir.vpk из папки dota_russian – всё вернётся как было.

Почему не работает на английской версии?
В английской версии нет отдельной папки dota_english, а мод работает только через подмену языковых VPK-пакетов. Valve ограничили этот механизм для английского языка.

🛠️ Сборка из исходников (для разработчиков)
Установи Python 3.11+ и зависимости:

bash
pip install -r requirements.txt
Убедись, что папка tools со всеми инструментами лежит в корне проекта.

Запусти сборку:

bash
pyinstaller buildbuild.spec
Готовый .exe появится в папке dist/.

Или используй прямую команду:

powershell
C:\Users\ТВОЙ_ПОЛЬЗОВАТЕЛЬ\AppData\Local\Programs\Python\Python311\python.exe -m PyInstaller --onefile --windowed --hidden-import pkgutil --hidden-import importlib --add-data "src/data;data" --add-data "src/assets;assets" --paths src src/main.py
